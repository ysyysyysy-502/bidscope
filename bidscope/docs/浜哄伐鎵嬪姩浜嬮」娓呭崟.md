# 人工手动事项清单

下面这些事项不能由 Demo 自动完成，需要队员手动操作或由企业教练确认。

## 1. 真实数据源核验

### 政府公开源

建议优先：

- 中国政府采购网；
- 全国公共资源交易平台；
- 一个省级公共资源平台，如上海、安徽、广东。

需要人工确认：

- 是否存在可稳定访问的列表页、搜索页、详情页；
- 页面是否允许自动化访问；
- 是否有 robots、服务条款、频率限制；
- 详情页字段是否能稳定抽取；
- 附件链接是否公开可下载；
- 更正、结果、合同公告如何与原项目关联。

### API 数据源

你给的线索是：

```text
https://console.api.gov-bid.com/bbiao-gateway/dashboard
```

需要人工完成：

- 注册账号；
- 确认是否真的有 300 次免费试用；
- 获取 API Key；
- 下载或截图接口文档；
- 记录字段名、调用限制、计费方式、更新频率；
- 用 5—10 条真实响应替换 `backend/app/data/notices_api_t2.json` 的样例数据。

### 商业聚合站

建议优先：剑鱼标讯；备用：标标达、千里马、采招网。

需要人工完成：

- 确认免费状态、注册状态、付费状态分别能看到哪些字段；
- 截图记录遮罩字段、会员字段、验证码触发情况；
- 不能绕过验证码、付费墙或遮罩；
- 只采集账号当前合法可见的字段；
- 将联系人、画像、关系分析等不可见字段标记为 `access_restricted`。

## 2. 飞书能力核验

需要人工完成：

- 创建飞书自建应用或机器人；
- 申请机器人消息、文件上传、多维表格读写权限；
- 创建多维表格，字段至少包括标题、来源、证据等级、摘要、标签、置信度、审核状态；
- 验证至少 1 项飞书原生 AI 能力，例如 AI 字段生成摘要 / 标签 / 理由；
- 保存可复查证据：输入记录 ID、AI 输出字段、状态变化截图。

注意：后端模型生成摘要只能作为业务降级，不能替代“飞书原生 AI 能力”验收。

## 3. GitHub 提交前检查

- README 不要写“已真实接入全部外部平台”；
- 指标写成 POC 目标，不写成已达成；
- 删除真实 Cookie、Token、手机号、密码；
- `.env` 不提交，只提交 `.env.example`；
- 用样例数据跑通 Demo；
- 录制 2—3 分钟演示视频：输入问题、查看意图、查看结果、下载 Word。
