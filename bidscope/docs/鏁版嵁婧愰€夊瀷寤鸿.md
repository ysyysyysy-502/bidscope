# 数据源选型建议

组长要求：政府信息 + 有 API 的数据网站 + 一个商业网站。建议第一轮按以下顺序验证。

| 类型 | 首选 | 备用 | 放进系统的证据等级 | 验证重点 |
|---|---|---|---|---|
| 政府信息源 | 中国政府采购网 | 全国公共资源交易平台 / 省级公共资源平台 | T0_CANONICAL | 列表、详情、附件、发布时间、项目编号、条款允许范围 |
| API 数据源 | 你提供的 gov-bid API 试用入口 | 云市场招投标 API | T2_DISCOVERY | API Key、字段、价格、限流、更新速度、是否有附件 |
| 商业网站 | 剑鱼标讯 | 标标达 / 千里马 / 采招网 | T2_DISCOVERY | 免费可见字段、登录可见字段、会员遮罩、验证码、导出限制 |

第一轮不要追求“网站多”，而是每类先跑通 5—10 条可复查样本：

1. 能搜索；
2. 能拿详情；
3. 能抽取五字段；
4. 能发现附件链接；
5. 能标记证据等级和权限状态；
6. 能进入 Word。
