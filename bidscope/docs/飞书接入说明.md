# 飞书接入说明

当前仓库未真实接入飞书，原因是需要租户权限、应用凭证和多维表格配置。GitHub Demo 中只保留接口和交付口径。

## 推荐 POC 闭环

1. Web 或飞书机器人收到自然语言问题；
2. 后端执行采集、清洗、去重、增量；
3. 标讯结果写入飞书多维表格；
4. 飞书原生 AI 字段生成摘要 / 标签 / 理由；
5. 低置信结果进入人工审核；
6. 审核通过后机器人发送卡片和 Word 链接。

## 必须人工取得的证据

- 飞书应用 ID 与权限截图；
- 多维表格字段截图；
- 至少 1 条 AI 字段输入记录；
- AI 字段输出结果；
- 审核状态变化；
- 机器人卡片或消息回执。
