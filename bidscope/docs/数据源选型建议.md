# 数据源选型建议

## 政府公开源（T0 官方正式事实）

### 首选

**中国政府采购网** (https://www.ccgp.gov.cn/)
- 覆盖全国中央、国家机关采购
- 结构完整、字段标准
- 提供搜索和订阅接口
- 附件通常为公开可下载

**全国公共资源交易平台** (https://www.cnshu.cn/)
- 统一汇聚地方平台招投标数据
- 支持跨地区搜索
- 字段相对规范

### 备选

地方性平台（以上海为例）：
- 上海市公共资源交易服务平台
- 专业性更强，服务器和算力项目集中度高

---

## API 数据源（T2 发现线索）

### 推荐

**公开投标标讯 API 服务**
- 例如：爬虫类或聚合类 API 服务商
- 优点：更新快、字段丰富、可订阅
- 缺点：多数需付费或有试用限制

### 集成要点

- 确认免费试用次数和有效期
- 记录调用限制和计费方式
- 测试响应时间和准确率
- 样例数据：保存 5—10 条真实响应用于 Demo

---

## 商业聚合源（T2 补漏和遮罩边界）

### 首选

**剑鱼标讯** (https://www.jianyu.ai/)
- 覆盖全国招投标数据
- 提供免费订阅和付费高级功能
- 字段丰富但存在会员限制

### 备选

- **标标达** (https://www.zbdwin.com/)
- **千里马** (https://www.qianlima.com/)
- **采招网** (https://www.caizhaow.com/)

### 合规处理

**必须明确记录：**

1. **免费账号可见字段**
   - 标题、发布时间、采购人、招标代理
   - 来源链接、摘要

2. **付费/会员隐藏字段** → 标记 `access_restricted`
   - 联系人及电话
   - 供应商报价画像
   - 关键词深度分析
   - 采购历史分析

3. **验证码和登录限制**
   - 一旦遇到验证码 → 停止采集
   - 标记该源状态为 `access_restricted` 或 `automation_prohibited`
   - **严禁尝试绕过**

---

## 海外平台（可选扩展）

如果项目涉及跨境采购或海外基础设施：

- **SAM.gov** (美国政府采购)：结构化强，公开 API
- **TED** (欧盟招标)：多语言，字段标准
- **UNGM** (联合国)：高可信，但项目有限

---

## 资讯补漏源（早期信号）

### 可选集成

- 行业新闻聚合（如专业数据中心、AI 基础设施新闻）
- 企业融资和扩产新闻
- 供应链预警

### 用途

- 标记为 "待核验线索" (T2/T3)
- 必须回源政府公开源或 API 源才能升级为正式公告

## Demo 中的模拟设置

当前 Demo 中的样例数据分布：

```
├── backend/app/data/
│   ├── notices_govt_t0.json      # 政府公开源模拟（T0 正式）
│   ├── notices_api_t2.json       # API 源模拟（T2 线索）
│   └── notices_commercial_t2.json # 商业聚合源模拟（T2 线索，字段遮罩）
```

后续替换时只需替换数据源响应部分，不改动核心处理逻辑。
