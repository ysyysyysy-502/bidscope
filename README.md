# 标讯罗盘 / BidScope

> 2026 AI 先锋未来人才大赛 · 超聚变企业命题
> 
> 一句话完成多源标讯的检索、订阅、审计与 Word 交付。

## 📋 开题报告

### 【Part 1】命题前置分析与洞察

企业真实标讯分散在六类网络：

- **政府/公共平台与采购人自有门户** 提供正式事实
- **行业协会** 补充标准、资质和主体知识
- **商业聚合站** 扩大召回却存在遮罩、转载和预测
- **TED、SAM.gov、UNGM** 等海外平台结构化强但涉及语言、币种和时区
- **新闻与行业资讯** 能提前暴露立项、扩产和数据中心建设信号，却不能替代公告

**核心矛盾不是"抓到更多网页"，而是：**

1. 区分正式证据与早期线索
2. 回源核验关键字段
3. 识别同项目的意向、招标、更正和结果阶段
4. 持续只交付新增、相关、可追溯的信息

### 【Part 2】整体解决方案设计

**"标讯罗盘"面向超聚变区域销售与商机运营**，用一句话完成服务器、算力及AI基础设施标讯的检索、订阅与Word交付。

#### 核心架构："证据通道 ＋ 发现通道"

- **证据通道**：政府平台、企业门户和海外官方源负责正式事实
- **发现通道**：商业聚合、协会与资讯源负责补漏和早期信号
- **验证流程**：回查原始公告后才进入正式结果

#### 技术栈（入围阶段）

- 前端：**Vue 3**
- 后端：**FastAPI**
- 队列：**Celery/Redis**
- 数据库：**PostgreSQL**
- 数据源：接入 1 个公开源与 1 个用户授权登录源

#### 合规边界

- 人工登录后复用加密会话
- 遇验证码、付费墙或权限不足即暂停
- 受控 AI 只解析主题、地区、时间、频率并生成带证据的相关性理由
- 事实字段、三级去重、重叠增量、推送账本和Word由确定性程序完成

#### 交付物与验收

结果保留五字段、证据等级和失败说明，并写入飞书多维表格：
- ✅ 验证至少 1 项飞书原生 AI 能力
- ✅ 低置信审核及机器人卡片与Word推送
- ❌ 后端模型仅作业务降级，不计作飞书AI验收

#### 验证方式

- **准确率指标**：以 30 条问法、每源 50 条详情和 100 条标注公告验证
- **价值衡量**：发现时效、节省工时和线索采纳率

## ✨ 核心能力演示

### 前端工作台
- Vue 3 单页问答界面
- 自然语言输入
- 结构化意图展示
- 标讯结果浏览
- Word 一键下载

### 后端处理链路
1. **自然语言意图解析**：主题、地区、时间范围、频率
2. **多源数据采集**：政府、API、商业三类数据源
3. **标准化处理**：统一标讯结构与字段
4. **分层证据**：T0/T1/T2/T3 证据分级
5. **智能去重**：三级确定性去重（URL / 正文哈希 / 项目编号）
6. **增量推送**：避免重复推送相同 notice
7. **Word 生成**：包含正式公告和待核验线索

## 🔐 合规声明

本 Demo **默认使用脱敏样例数据和模拟连接器**。真实接入外部网站前，需要逐源确认：

- ✅ robots / 服务条款 / API 使用协议
- ✅ 是否允许自动化访问
- ✅ 是否需要用户授权登录
- ✅ 是否存在验证码、付费墙、CA 或导出限制
- ✅ 账号可见字段与会话有效期
- ✅ 限速、缓存、退避和人工续登流程

系统遇到验证码、付费墙、权限不足或明确禁止自动化时，应停止采集并标记 `access_restricted` 或 `automation_prohibited`，**不得尝试绕过**。
