# 给组长的汇报话术

我已经先把工程雏形搭起来了，不是只做一个页面，也不是直接硬爬网站，而是把三类数据源的连接器、统一标讯结构、意图解析、证据分层、相关性评分、去重、增量账本和Word交付的完整主流程搭起来。

目前三类源先用脱敏样例数据模拟：

- 政府公开源代表中国政府采购网 / 全国公共资源交易平台；
- API 源代表后续要注册试用的招投标 API；
- 商业源代表剑鱼 / 千里马 / 采招网，只处理合法可见字段，遮罩字段会标记受限。

下一步需要人工做三件事：

1. 注册并试用 API，拿到 Key 和接口文档；
2. 选定一个政府网站，确认页面和附件能稳定抽取；
3. 准备商业网站账号和飞书权限，确认不能触碰的验证码、付费墙和遮罩边界。

这样 GitHub 上先展示完整工程能力，后续真实源只是替换连接器，不需要推翻主流程。
